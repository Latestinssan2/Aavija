Getting Started

Aavija is a native hand-gesture file sharing app between Android, macOS, and Windows over local Wi-Fi. No cloud, no tracking.

  • Install the app on two devices on the same Wi-Fi.
  • On Android, open Aavija and make it discoverable.
  • On macOS/Windows, open Aavija and pair using the 6-digit PIN.
  • Turn on Gesture Mode to use GRAB/RELEASE sharing.

Build from Source

Android:  cd android && ./gradlew assembleDebug
macOS:    cd mac && xcodegen generate --spec project.yml && xcodebuild ...
Windows:  dotnet build windows/AavijaWindows/AavijaWindows.csproj
    

      
Protocol

      
Phones are the TLS listeners. Desktops are clients. Pairing uses a 6-digit PIN bound to the certificate fingerprint. File transfers require token authentication before bytes. See docs/PROTOCOL.md.
