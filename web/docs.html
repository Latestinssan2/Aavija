Aavija Documentation

Introduction

Aavija is a native hand-gesture file and screenshot sharing app between Android, macOS, and Windows over local Wi-Fi. No cloud, no tracking, no data leaves your network.

What makes Aavija different?

Most sharing apps require an account or cloud relay. Aavija pairs devices with a 6-digit PIN over TLS 1.3 on your local network. Files never leave your Wi-Fi. Gesture detection runs entirely on-device.

Getting Started

  1. Install Aavija on two devices on the same Wi-Fi.
  2. On Android, open the app (it becomes discoverable).
  3. On macOS/Windows, open Aavija and select the phone.
  4. Enter the 6-digit PIN shown on the desktop into the phone.
  5. Turn on Gesture Mode. GRAB to hold, RELEASE to send within 10s.
First-time pairing walkthrough

When you tap a Mac/Windows device on Android, the desktop generates a 6-digit PIN and displays it. The phone shows a PIN entry dialog. Type the PIN and press Submit. Five wrong attempts lock pairing for 5 minutes. Once paired, a token is stored and the PIN is never needed again.

Gesture Mode tips

Hold your hand 30–60 cm from the camera. GRAB = close fist, RELEASE = open palm. The hand must be visible for ~0.5s to register. Gesture Mode uses the front camera at ~10 fps; nothing is recorded.

Build from Source

Android:  cd android && ./gradlew assembleDebug
macOS:    cd mac && xcodegen generate --spec project.yml && xcodebuild ...
Windows:  dotnet build windows/AavijaWindows/AavijaWindows.csproj
      

        
Protocol

        
Phones are TLS listeners. Desktops are clients. Messages are newline-delimited JSON over TLS.

        

          Handshake details
          
Phone sends a challenge (random salt). Client replies with pair (PIN proof bound to cert fingerprint) or auth (token). Phone replies paired/authenticated/rejected/locked. All file bytes require a valid token.

        

        

          Gesture matching
          
One side GRABs (holds a file/screenshot), the other RELEASEs within 10s. The connecting phone drives A2A transfers; the Mac/Windows drives Mac↔phone transfers.

        

      


      

        
Security

        
    
          
  • TLS 1.3 with self-signed certs and fingerprint pinning.
    • 
          
  • Token auth before any file byte.
    • 
          
  • Path traversal rejected; writes only under Downloads/GestureShare.
    • 
          
  • 200 MB file cap.
    • 
          
  • No silent plaintext fallback.
    • 
          
  • 5 PIN attempts then 5-minute lockout.
    • 
        

        

          Threat model
          
A man-in-the-middle swapping certificates produces a proof bound to a different fingerprint and is rejected. Replay attacks are prevented by per-connection salts. Unpaired devices never receive file bytes.

        

      


      

        
Known Limitations

        

          Mac↔Mac direct sharing
          
macOS cannot run the listener (Network.framework listener fails). Use a phone or Windows listener as a relay.

        

        

          Windows gesture tracking
          
Uses a Python/MediaPipe sidecar. A native C++ MediaPipe DLL is scaffolded but requires a local MediaPipe build.

        

        

          Background camera on Android
          
Requires a foreground service and camera permission. Android may still restrict background camera on some OEMs.
