Privacy Policy

Aavija does not collect, transmit, or store personal data on any server. All file transfers happen over your local Wi-Fi network using TLS 1.3. No cloud services are used.

Camera and screen capture are used only while Gesture Mode is enabled and only for on-device hand detection and one-shot screenshots. No frames are recorded or transmitted.

Pairing uses a 6-digit PIN and certificate fingerprint binding. Session tokens are stored locally on your device.

For questions, contact the project maintainer via GitHub.
